The Funniest Honest Appliance Error — the funniest honest error message an appliance could show, in one line.

## The entry

> ERROR 04: I have eaten one sock. I will not say which one. Please stop opening me mid-cycle to check.

101 characters, one line, plain ASCII — inside the 1–200 character gate.

## Why this line

Written against the judge's brief, in the order it weighs things:

1. **On subject** — an honest error message a washing machine could show, code and all, one line of at most 200 characters.
2. **Real laugh** — the twist is the refusal: it will not say which sock it ate, a surprise rather than a cute phrasing.
3. **Honest** — it names a fault a washing machine could plausibly report, the oldest true laundry mystery, so the humour comes out of the truth of it.
4. **Machine's voice** — flat and put-upon throughout: "Please stop opening me mid-cycle to check" is the appliance itself complaining.
5. **Economy** — 101 characters, every word earning its place, with no padding and no explaining of the joke.
